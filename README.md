# 프로젝트 파라메트릭 (Project Parametric)

> **상태공간 조합형 파라미터 대전 카드 게임**  
> React + TypeScript + Vite 기반 웹 게임

플레이어가 **기초 파라미터 상태공간**과 **규칙 상태공간**으로 분리되어 있으며, 규칙 카드 자체가 하나의 특수한 파라미터로 취급되는 전략 카드 대전 게임입니다.

---

## 주요 특징

- **3가지 카드 시스템**:
  - **파라미터 카드**: `카페인`, `자존감`, `배터리`, `집중력`, `적금`, `월세`, `흑역사` 등 7종의 파라미터와 부호(`+` / `-`)를 가집니다.
  - **주사위 카드**: 매 턴 2장을 드로우해 유리한 1장을 선택하여 파라미터에 적용합니다.
  - **룰 카드**: 승패 조건, 드로우 수, 주사위 규칙, 연산 방식 등 게임의 모든 규칙을 변경할 수 있습니다. 동일 영역(`Domain`)의 룰 카드가 충돌하면 1장만 남기고 버립니다.
- **상태공간 조합 메커니즘**:
  - 규칙 상태공간은 파라미터 상태공간에 포함되며, **`침공`**, **`역전`**, **`인형술사`** 카드를 통해 자신과 상대의 규칙/파라미터 상태공간을 일시적으로 조합해 턴을 진행할 수 있습니다.
  - 승패 판정은 턴 종료 시 조합이 해제된 후 각 플레이어의 원래 상태공간을 기준으로 수행됩니다.
- **모더레이터 카드 (`모드 카드: 스탠다드 프로토콜 v1.0`)**:
  - 모든 플레이어에게 공통으로 적용되는 최우선 메타규칙으로, 게임 내 `📜 모드 카드` 버튼을 통해 언제든지 확인할 수 있습니다.
- **비선형 2-Phase 난이도 시스템 (`0.1` ~ `10.0`)**:
  - **Phase I (`0.1` ~ `5.0`)**: 난이도가 오를수록 파라미터 음수(`-`) 확률과 주사위 고눈(5~6) 확률이 동시에 상승하는 하이리스크·하이리턴 구간입니다.
  - **Phase II (`5.1` ~ `10.0`)**: 파라미터 부호 비율은 표준(`3.5`, `50% : 50%`)으로 회귀하는 대신, `시한폭탄`, `부채 상환`, `규칙 잠금` 등 불리한 압박형 룰 카드 비중이 비선형으로 급증합니다.
- **대전 모드**:
  - **1인 vs AI**: 난이도에 따라 전술 수준이 달라지는 AI 오토마타와 대전합니다.
  - **로컬 2인 대전**: 한 화면에서 번갈아 가며 2인 대전을 즐길 수 있습니다.

## 기본 승리 및 패배 조건

- **승리 조건** (모드 카드 기본 규칙, 룰 카드로 변경 가능):
  1. 단일 파라미터 **`+15` 이상** 달성
  2. 서로 다른 **3개 이상**의 파라미터가 동시에 **`+8` 이상** 달성
  3. 모든 파라미터의 **총합 `+25` 이상** 달성
- **패배(파산) 조건**:
  - 단일 파라미터가 **`-12` 이하**가 되면 파산하여 패배합니다.

## 시작하기

### 요구 사항
- Node.js (v20 이상 권장; 테스트 실행 시 `--experimental-strip-types` 지원 버전)
- npm

### 설치 및 실행
```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

### 빌드 및 테스트
```bash
# 엔진 단위 테스트 실행
npm test

# TypeScript 타입 체크 및 프로덕션 빌드
npm run build

# 빌드 결과 미리보기
npm run preview
```

## 프로젝트 구조

```text
ppm-tcg/
├── GAME_DESIGN.md            # 상세 게임 기획서 및 카드 목록
├── index.html
├── package.json
├── src/
│   ├── App.tsx               # 메인 UI, 난이도 선택 팝업, 모드 카드 모달
│   ├── main.tsx              # React 엔트리 포인트
│   ├── styles.css            # 다크 테이블탑 UI 스타일
│   ├── types/

│   ├── data/
│   │   └── cards.ts          # 7종 파라미터 및 22종 룰 카드 템플릿, 덱 빌더

│       ├── difficulty.ts     # 비선형 2-Phase 난이도 확률 계산 모델
│       └── gameEngine.ts     # 턴 진행, 상태공간 조합, 룰 충돌, AI 로직
└── tests/
    └── engine.test.ts        # 게임 엔진 및 난이도 곡선 단위 테스트
```
